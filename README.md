# HabitTracker 🚀

A modern, full-featured Android application designed to help users build and maintain healthy habits through consistent tracking, visual analytics, and smart reminders.

## ✨ Features

### 🔐 Secure Authentication
- **User Login & Signup**: Personalized experience for every user.
- **Advanced Validation**: Robust password requirements to keep user data safe.
- **Security Lock**: App automatically locks after 3 failed login attempts to prevent unauthorized access.

### 📅 Habit Management
- **Full CRUD Support**: Create, Read, Update, and Delete habits with ease.
- **Detailed Scheduling**: Set specific start and end times for each habit.
- **Daily Check-ins**: Simple one-tap completion tracking from the home screen.

### 📊 Analytics & Progress
- **Streak Tracking**: Stay motivated with automatically calculated current streaks.
- **Completion Rates**: Monitor your consistency with 30-day completion percentage stats.
- **Visual History**: A dedicated history tab featuring a monthly calendar grid to visualize your progress over time.

### 🔔 Smart Reminders
- **System Alarms**: Automatically schedules Android system alarms based on your habit start times.
- **Local Notifications**: Receive custom "Time for Habit" reminders even when the app is closed.

## 🛠 Tech Stack

- **UI Framework**: [Jetpack Compose](https://developer.android.com/jetpack/compose) (Modern Android UI)
- **Design System**: Material 3
- **Language**: Kotlin 2.0+
- **Database**: [Room Persistence Library](https://developer.android.com/training/data-storage/room)
- **Annotation Processing**: Kotlin Symbol Processing (KSP)
- **Architecture**: MVVM with Flow and Coroutines
- **Navigation**: Jetpack Compose Navigation

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/srinidhiguttal/HabitTracker.git
   ```
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Sync the project with Gradle files.
4. Run the app on an emulator or physical device (API 26+).
